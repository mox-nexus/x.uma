Documentation

Organised by what you came to do. Start with a tutorial if x.uma is new to you, reach for a how-to when you have a specific problem, and read the explanations when you want to know why it works the way it does.

Tutorials

Start here. Working code in a few minutes.

  • Rust Build an HTTP route matcher with rumi-core and rumi-http.
  • Python The same matcher in pure Python, or Rust-backed via PyO3.
  • TypeScript The same matcher in pure TypeScript, or WASM-backed.

How-to

Solve one specific problem.

  • Route on a header Match a request by header value, with a fallback when nothing matches.
  • Add a custom input Teach the engine to read a field it does not know about yet.
  • Debug why something matched Read the evaluation trace to see the path taken through the tree.
  • Share one config across languages Author rules once and evaluate them identically in three runtimes.

Explanation

Understand why it works this way.

  • The matching pipeline How a context becomes a decision, one stage at a time.
  • Type erasure and ports Why erasing at the data level keeps matchers shareable across domains.
  • Architecture Hexagonal core, domain adapters, and the extension seam.
  • Security model ReDoS protection, depth limits, and the resource bounds config load enforces.
