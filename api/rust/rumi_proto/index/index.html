Action sites numbered in document order, so a binding returns an index and holds the actions itself (D-056).

The walk is the same for every consumer of this crate, which is what makes the PyO3 and wasm bindings number a document identically: a pre-order walk of the IR, list entries in written order, tree entries by sorted key, and each matcher’s fallback after its entries. Two loads of one document produce one table.
